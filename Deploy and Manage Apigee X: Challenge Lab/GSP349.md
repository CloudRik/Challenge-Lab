### 🔹 TASK 4

#### STEP-4.1 : Command 1: Create Policy

```bash
gcloud compute security-policies create protect-apigee
```


#### STEP-4.2 : Command 2: Then Create the Rule

```bash
gcloud compute security-policies rules create 1000 \
  --security-policy protect-apigee \
  --expression "evaluatePreconfiguredExpr('rce-v33-stable')" \
  --action "deny-403" \
  --description "Deny Remote Code Execution"
```

#### STEP-4.3 : Command 2: Attached to LB

```bash
gcloud compute backend-services update apigee-proxy-backend \
  --security-policy protect-apigee --global
```
